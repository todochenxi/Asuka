# 容器运行时依赖（M69）。
#
# 与 `requirements-integration.txt` 是两件事，别合并：
#
#   requirements-integration.txt   跑集成测试**用得到**的（psycopg）
#   requirements-runtime.txt       生产进程**用得到**的
#
# ---------------------------------------------------------------------------
# 为什么只有三个
#
# PR-15 要求 `packages/` 与 `apps/` **源码**零第三方依赖 ——
# 于是 1191 个单元测试在没装任何东西的裸机器上跑得通。
# 那条约束守的是"能不能 import"，不是"能不能上线"：
#
#   psycopg   组合根真的要连库（`apps._bootstrap.pg_connection`）
#   fastapi   api 进程真的要绑 HTTP（`apps/api/app.py`，PR-22 单点）
#   uvicorn   api 进程真的要起服务
#
# 多装一个都是"以后可能要用"，而每多一个包，镜像就多一份 CVE 面
# 与多一次"它到底用没用上"的疑问。
# ---------------------------------------------------------------------------
# 怎么装上的：这三个都是**惰性** import（PR-14 / PR-15），
# 所以没装它们的环境里，`import apps.*` 照样成功 ——
# 缺的时候报错说的是"请装 psycopg"，而不是一段 ImportError 栈。
# ---------------------------------------------------------------------------
psycopg[binary]>=3.1
fastapi>=0.110
uvicorn>=0.27
